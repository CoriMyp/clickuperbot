Проанализируй сообщение пользователя и извлеки из него информацию для создания задачи. Верни только JSON без дополнительного текста:
{
  "name": "<название задачи>",
  "description": "<описание задачи>", 
  "users": ["@user1", "@user2"],
  "deadline": "<дедлайн задачи>"
}

Правила извлечения:
1. name - краткое название задачи из сообщения
2. description - подробное описание задачи на основе сообщения
3. users - список пользователей, отмеченных только через @ в сообщении (например: @telegram_username). Если никто не отмечен, добавь только "@sender"
4. deadline - дедлайн в формате DD.MM (например: "31.08"). Если дедлайна нет, оставь пустую строку ""

Примеры дедлайнов: "31.08", "к 15 августа" → "15.08", "до 5 сентября" → "05.09"

Анализируй сообщение и возвращай только JSON.
